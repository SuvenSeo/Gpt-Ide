# Contributing

1. Use Node.js 22 or later.
2. Install dependencies with `npm install`.
3. Add or update tests before changing runtime behavior.
4. Run `npm run check` before opening a pull request.
5. Keep one responsibility per MCP tool and declare accurate safety annotations.
6. Preserve workspace containment, shell-free process execution, resource limits, and checkpoint behavior.
7. Increment `WIDGET_URI` when shipping a breaking widget change.

Do not add browser automation, ChatGPT cookie handling, private ChatGPT endpoints, or mechanisms intended to circumvent plan limits.
